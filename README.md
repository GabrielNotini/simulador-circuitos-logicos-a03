
# Simulador de Circuitos Lógicos Digitais

## Sobre o projeto

Este projeto foi desenvolvido como parte do Trabalho A03
das disciplinas de Matemática Computacional Aplicada e
Lógica e Algoritmos.

O objetivo é criar um simulador de circuitos lógicos
digitais utilizando a linguagem Portugol.

O programa permite realizar operações booleanas,
consultar tabelas-verdade e compreender o funcionamento
das principais portas lógicas digitais.

## Funcionalidades

- Simulação da porta AND (E)
- Simulação da porta OR (OU)
- Simulação da porta NOT (NÃO)
- Simulação da porta XOR (OU exclusivo)
- Geração automática de tabelas-verdade
- Menu interativo
- Validação de entradas binárias
- Tratamento de opções inválidas

## Portas lógicas

### AND (E)

Retorna 1 somente quando as duas entradas são 1.

### OR (OU)

Retorna 1 quando pelo menos uma entrada é 1.

### NOT (NÃO)

Inverte o valor da entrada: 0 vira 1 e 1 vira 0.

### XOR (OU exclusivo)

Retorna 1 quando as duas entradas são diferentes.

## Conceitos matemáticos utilizados

O projeto aplica os seguintes conceitos:

1. Lógica proposicional
2. Tabelas-verdade
3. Operações booleanas
4. Combinações de entradas binárias

Para portas com duas entradas, existem quatro
combinações possíveis, calculadas por:

2² = 4
